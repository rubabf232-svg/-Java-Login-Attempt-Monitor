# 🔐 Java Login Attempt Monitor

A simple Java-based cybersecurity tool that monitors failed login attempts and identifies potentially suspicious login activity.

## 📌 Overview

The Login Attempt Monitor is a beginner-friendly cybersecurity project developed using Java.

It simulates monitoring failed login attempts for a username and assigns a security status based on the number of failed attempts.

The project is designed for learning Java programming and understanding the basic concept of brute-force attack detection.

## ✨ Features

- Accepts a username
- Records failed login attempts
- Counts failed attempts
- Detects multiple failed attempts
- Generates security warnings
- Identifies potential brute-force activity
- Simple command-line interface

## 🛠️ Technologies Used

- Java
- Java Scanner
- Object-Oriented Programming
- Conditional Statements
- Loops
- Methods
